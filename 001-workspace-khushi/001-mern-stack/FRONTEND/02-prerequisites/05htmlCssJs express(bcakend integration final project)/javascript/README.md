# JavaScript Fundamentals and Browser Practice

This directory contains small, single-concept examples. The numbered folders
provide topic-wise navigation guides. All original source files remain directly
inside this directory; no code has been deleted, moved, or duplicated.

## 1. Language basics

- Variables and types: `variable.js`, `Datatypes.js`, `operation.js`
- Text and numbers: `string.js`, `math.js`, `mathpi.js`, `math_pi.js`, `date.js`
- Arrays: `array.js`, `arrays.js`, `fillter_map.js`
- Conditions and loops: `controlflow.js`, `forloop.js`, `do_while.js`, `in_of-for _each.js`

## 2. Functions and object-oriented JavaScript

- Functions and scope: `function.js`, `scope.js`, `call.js`, `invoked.js`, `this_and_arrow.js`
- Objects: `object.js`, `object1.js`, `objectdestructure.js`, `getter-setter.js`
- Classes and OOP: `myclasses.js`, `inheritance.js`, `oops.js`, `satickprop.js`

## 3. DOM and events

- DOM selection and traversal: `dom.html`, `dom2.html`, `dom3.html`, `partofdom2.html`
- Browser events: `events.html`
- Styling/event demo: `border.html` with `boredr.js` and `Style.css`

## 4. Promises and APIs

- Promise basics: `promises.html`, `promises.js`
- API connection: `apiconnection.html`
- The complete project is in the sibling `javascriptwebpage` directory.

Open HTML files in a browser. JavaScript-only files are learning snippets and can be run with Node.js when they do not use browser objects such as `document` or `window`.
