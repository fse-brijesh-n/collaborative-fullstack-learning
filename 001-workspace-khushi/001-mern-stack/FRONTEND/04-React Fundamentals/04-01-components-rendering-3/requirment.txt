Main Pages Flow

For the backend, you can use:

React + Node.js + Express.js + MongoDB

Main database collections:

Admin
Users
Tasks

Each Task should contain:

title
description
assignedUser
status
priority
dueDate
createdAt
updatedAt

This structure is clean and suitable for a full Admin User & Task Management Dashboard project.
